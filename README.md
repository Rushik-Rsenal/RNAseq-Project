### Purpose
Differential gene expression analysis was conducted on the RNAseq data from the cerebellum of 2D2 mice. This modelled how the gene expression in cerebellum changes since the onset of Upper Respiratory in Multiple-Sclerosis Patients, resulting in exacerbated symptoms.
